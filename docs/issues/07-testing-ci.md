# Automatizar pruebas e integración continua

## Objetivo

Ejecutar la suite en cada Pull Request y cubrir reglas, usuarios, conflictos y criterios.

## Criterios de cierre

- Prueba independiente contra doble reserva.
- Pruebas de validación y autorización.
- Workflow ejecutado en Pull Requests y `main`.
- `docs/testing.md` refleja la cobertura real.
