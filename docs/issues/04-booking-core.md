# Implementar reserva mínima y prevención de conflictos

## Objetivo

Crear el núcleo transaccional que registra una reserva válida y rechaza solapamientos.

## Criterios de cierre

- CA-02, CA-03 y CA-04 automatizados.
- Un rechazo no crea registros parciales.
- Intervalos consecutivos se permiten según la especificación inicial.
- El Pull Request incluye evidencia de las pruebas.
