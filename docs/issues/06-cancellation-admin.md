# Incorporar cancelaciones, bloqueos y auditoría

## Objetivo

Completar la operación del usuario y los controles mínimos del administrador.

## Criterios de cierre

- El usuario cancela únicamente reservas propias.
- Una cancelación libera disponibilidad sin borrar historial.
- Los bloqueos impiden reservas conflictivas.
- Las acciones relevantes generan auditoría.
