# Gestionar cambio inesperado de especificación

## Objetivo

Demostrar el ciclo completo de un requisito agregado a mitad del desarrollo.

## Criterios de cierre

- Solicitud registrada antes de modificar código.
- Requisitos, criterios y plan actualizados.
- Prueba nueva falla contra la versión anterior.
- Código corregido y suite completa aprobada.
- Evidencia conservada en Pull Request e historial.
