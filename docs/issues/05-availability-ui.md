# Consultar disponibilidad y alternativas

## Objetivo

Permitir que el usuario encuentre horarios libres y reciba alternativas ante un conflicto.

## Criterios de cierre

- Consulta por cancha y fecha.
- Reservas y bloqueos se reflejan en disponibilidad.
- Los mensajes no revelan datos ajenos.
- CA-01 y CA-09 automatizados.
